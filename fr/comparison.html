Le plugin Gmail d'Odoo fonctionne-t-il sur Odoo auto-hébergé / on-premise ?

Réponse courte : uniquement si vous modifiez son code source et le déployez vous-même. C'est là toute la différence.

Pour utiliser le plugin OFFICIEL sur Odoo auto-hébergé (domaine personnalisé), la documentation d'Odoo elle-même exige de :
  1. Télécharger le dépôt mail-client-extensions depuis GitHub
  2. Modifier login.ts pour supprimer la vérification du domaine odoo.com
  3. Modifier appsscript.json pour autoriser le domaine de votre serveur
  4. Le déployer comme votre propre projet Google Apps Script
  5. Le publier depuis le manifest et installer le module complémentaire
Avec notre extension :

Entrez l'URL de votre Odoo. C'est terminé. Sans code, sans déploiement. Fonctionne sur Community et Enterprise, tout domaine, Odoo 14–19.

Ce sont les étapes de la documentation officielle d'Odoo (mail_plugins/gmail) — nous décrivons leur processus, nous ne l'inventons pas.
