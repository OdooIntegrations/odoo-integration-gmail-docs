O plugin Gmail do Odoo funciona em Odoo self-hosted / on-premise?

Resposta curta: apenas se você editar o código-fonte e implantá-lo por conta própria. Essa é a verdadeira diferença.

Para usar o plugin OFICIAL em Odoo self-hosted (domínio personalizado), a própria documentação do Odoo exige que você:
  1. Baixe o repositório mail-client-extensions do GitHub
  2. Edite login.ts para remover a verificação do domínio odoo.com
  3. Edite appsscript.json para autorizar o domínio do seu servidor
  4. Implante-o como seu próprio projeto do Google Apps Script
  5. Publique a partir do manifest e instale o complemento
Com a nossa extensão:

Insira a URL do seu Odoo. Pronto. Sem código, sem implantação. Funciona no Community e Enterprise, qualquer domínio, Odoo 14–19.

Estes são os passos da própria documentação do Odoo (mail_plugins/gmail) — estamos descrevendo o processo deles, não o inventando.
