Key Features

person

Instant Contact Info

View Odoo contact details directly in Gmail's sidebar when you open an email. 22x faster than Google Apps Script. No developer setup — where the official plugin needs code and an Apps Script deployment for self-hosted Odoo, here it's just your URL.

dashboard

CRM, tasks & tickets at a glance

See opportunities, project tasks and helpdesk tickets associated with the contact — all in one sidebar. Create new ones in a click.

mail

One-click email logging

Log emails to Odoo records with one click. Attachments and thread history preserved.

sync

Auto-logging

Link a Gmail thread once and the extension keeps it synced with the Odoo record in the background. No manual logging again.

business

Multi-company support

Works across all the Odoo companies you have access to. The active company is auto-detected per record.

bolt

Lightning Fast

100-300ms response time with smart caching. No more waiting for slow integrations.
